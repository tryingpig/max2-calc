# max2-calc

추세추종 **맥스 2% 룰** 배팅 계산기. 시드에서 한 번에 잃어도 되는 돈을 정하고, 거기서 거꾸로
종목당 투자금 → 유닛 → 수량·손절가·목표가를 뽑는다.

- 주소: https://tryingpig.github.io/max2-calc/
- 폰에서 "홈 화면에 추가"하면 앱처럼 열린다 (PWA, 오프라인 동작)
- 시드·종목·매수가 등 입력값은 **그 기기 브라우저(localStorage)에만** 남는다. 저장소·서버로 가지 않는다.
- 시세는 손으로 입력한다. (자동 조회는 별도 서버가 필요해 다음 단계)

기준: 깡토 「진입시점·매수비중·손절기준」(2026-09-10) — 최대손실 = 시드×2%, 종목당 최대투자금 = 최대손실÷R,
최소 손익비 1:3, 유닛 = 장세(코스피 60일선) + 종목(3R 달성 +1 / 손절 −1).

아이콘은 `icon_spec.json` → `pixel-icon` 스킬로 생성.
